# CompTIA Tech+ (FC0-U71)

> A foundational IT certification for aspiring tech professionals and tech-adjacent roles.

---

## 📋 Overview

**CompTIA Tech+** is the modern, entry-level IT certification from CompTIA. Launched on **July 16, 2024**, it replaced the retired **CompTIA IT Fundamentals+ (ITF+)** (FC0-U61), which was fully retired on **July 31, 2025**.

Tech+ is designed to validate both foundational *knowledge* and practical, *hands-on skills* — a shift from ITF+'s more "awareness-level" approach. It bridges the gap between total beginner and job-ready entry-level professional by incorporating modern topics like **AI, cloud computing, and advanced cybersecurity**.

## 🗂️ Exam Domains & Weightings

The exam is organized into **6 core domains**:

### 1. 💻 IT Concepts and Terminology — *26%*
The largest domain. Covers the language and fundamentals of IT.
- Basic computing concepts and processing
- Notational systems: binary, hexadecimal, octal
- Units of measure: storage (KB, MB, GB, TB), speed, throughput
- Troubleshooting methodology (identify → research → implement → verify)
- Common IT terminology and acronyms

### 2. 🔧 Infrastructure — *18%*
Focuses on hardware and networking components.
- Internal computing components (CPU, RAM, storage, motherboard)
- Peripheral device setup and configuration
- Wired and wireless networking (TCP/IP, Wi-Fi standards)
- Virtualization concepts
- Cloud computing models (IaaS, PaaS, SaaS)
- Cloud deployment models (public, private, hybrid)

### 3. 📱 Applications and Software — *14%*
Covers how software works and is used.
- Operating systems: Windows, Linux, macOS
- Application software types and purposes
- Web browser features and settings
- Productivity software (word processors, spreadsheets, presentations)
- AI tools: chatbots, generative AI, and their practical use
- Application architecture (client-server, web-based)

### 4. 🖥️ Software Development Concepts — *10%*
An introduction to programming and development principles.
- Categories of programming languages (interpreted, compiled, scripting)
- Logic concepts (Boolean logic, conditionals, loops)
- Organizational techniques (algorithms, flowcharts, pseudocode)
- Foundational programming principles and best practices

### 5. 🗄️ Database Fundamentals — *13%*
Covers how data is stored, organized, and used.
- Database structures (tables, rows, columns, relationships)
- Types of databases (relational, NoSQL)
- Basic SQL commands: SELECT, INSERT, DELETE, CREATE
- Database backup methods and recovery concepts
- The value of data in decision-making and business intelligence

### 6. 🔒 Security — *19%*
Focuses on practical security practices.
- Identifying security threats and vulnerabilities
- Password management and best practices (MFA, password managers)
- Data encryption (at rest and in transit)
- VPN setup and use cases
- Physical security considerations
- Secure Wi-Fi practices
- Data privacy and protection principles

## 📈 Career Paths & Next Steps

Tech+ is a **stepping stone**, not a terminal credential. It prepares you for:

### Entry-Level Roles
- Help Desk Technician / IT Support Technician
- Desktop Support Specialist
- IT Assistant / Junior IT Technician
- Tech-adjacent business roles requiring digital literacy

### Certifications to Pursue Next

After earning Tech+, the natural progression is:

```
CompTIA Tech+ (FC0-U71)
       ↓
CompTIA A+ (Core 1 & Core 2)
       ↓
Specialize in one of:
  ├── CompTIA Network+       → Networking path
  ├── CompTIA Security+      → Cybersecurity path
  ├── CompTIA Cloud+         → Cloud computing path
  └── CompTIA Data+          → Data analytics path
```

## 🆚 Tech+ vs. ITF+ (What Changed?)

| Feature | ITF+ (FC0-U61) | Tech+ (FC0-U71) |
|---------|----------------|-----------------|
| **Focus** | Awareness-level | Applied, practical competence |
| **AI Content** | None | Chatbots, generative AI |
| **Cloud Content** | Basic | Expanded (IaaS/PaaS/SaaS) |
| **Security** | Basic | More advanced, hands-on |
| **Status** | Retired July 31, 2025 | Active |
| **Carryover** | ITF+ does NOT convert to Tech+ | Must pass FC0-U71 separately |

> **Note:** If you earned ITF+, your certification remains valid for life — but it is **not** automatically upgraded to Tech+.

## ✅ Exam Tips & Strategies

### Before the Exam
1. **Download the official exam objectives** from CompTIA — treat every bullet point as a potential exam question.
2. **Use practice tests** not just to memorize answers, but to identify *weak domains* by tracking your score per section.
3. **Do hands-on practice** — configure your home network, explore OS settings, try basic command-line tools.
4. **Take active notes** — summarize concepts in your own words, especially for software development and database topics.
5. **Avoid brain dumps** — CompTIA uses scenario-based questions; memorized dumps often fail when wording changes.

### During the Exam
- You have **60 minutes for up to 75 questions** — that's less than 1 minute per question.
- **Don't dwell** on hard questions — flag and move on, return at the end.
- **Read carefully** — scenario questions often hinge on one key detail.
- **Eliminate wrong answers** — even if unsure, process of elimination improves odds.

### Cost-Saving Tips
- **Student discounts** — Available through the CompTIA Academic Store.
- **Bundle deals** — Some CertMaster bundles include the exam voucher.
- **Seasonal sales** — CompTIA runs back-to-school and Black Friday promotions.
- **Employer reimbursement** — Many employers will cover the cost; always ask.

## 🏆 Certification Validity

Unlike most CompTIA certifications (e.g., A+, Security+, Network+ which expire every 3 years), **Tech+ is a "Certification for Life"** — it **never expires**.

However, an optional **Continuing Education (CE)** version exists:
- **Exam Code:** FC0-U71-CE
- Renewed on a 5-year cycle through CEUs (Continuing Education Units)
- Useful if you want to show ongoing professional development
